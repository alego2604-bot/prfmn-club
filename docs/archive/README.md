# Archivo histórico

Documentos de la fase anterior del repositorio (julio 2026), cuando el proyecto se concebía como «PRFMN Club», un software de gestión de gimnasios ligado a la marca PRFMN (incluía ideas de app de atleta y workouts).

**Ya no describen el producto.** Desde el 2026-10-01 este repositorio es **Business OS**, un software de gestión empresarial independiente, sin dependencia técnica de PRFMN (ver `../DECISIONS.md` y `../PROJECT_MASTER.md`). Se conservan solo como referencia histórica, sin borrar trabajo previo.
